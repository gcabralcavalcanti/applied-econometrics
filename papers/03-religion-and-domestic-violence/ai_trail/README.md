# Trilha de IA da Q4 (versão do curso, julho de 2026)

O que fica público da pesquisa feita com IA, revisado linha a linha para publicação:

| Arquivo | O que mostra |
|---|---|
| `RESEARCH_BRIEF.md` | a pergunta, a estratégia e as limitações combinadas com o agente |
| `MEMORY.md` | as decisões de método e de dados, na ordem em que foram tomadas |
| `quality_reports/` | os quatro pareceres adversariais (dois revisores críticos, uma verificação final) e o que cada um exigiu |

Os números citados aqui são os da versão do curso (5.030 municípios). A versão atual do artigo baixa os insumos do IBGE
pelo próprio código e tem 5.046 municípios (ver o README do artigo). Trechos cortados aparecem como `[trecho removido]`.
